Capabilities

Four capabilities, one governed pipeline

Not a chatbot with a system prompt — an explicit state machine where the model proposes, deterministic tools compute, and humans decide anything that matters.

01Policy & tariff Q&A

Answers in English, Kiswahili and code-mixed Sheng with document citations (doc id, page, effective date). Fees come from a structured tariff table via a deterministic tool — the LLM never does money math.

hybrid retrieval BM25 + dense → RRF · reranker · answerability gate → handoff, never guess

02Account assistant

Balance and mini-statement through typed tool calls with opaque handles — identity never travels in tool arguments. Ownership is resolved server-side; scopes gate every call.

zod-typed tools · acct_7f3a handles · scope enforcement · PII pseudonymised before external calls

03Loan pre-qualification packs

Payslip documents are extracted with per-field confidence and evidence, validated against Kenyan rules (KRA PIN format, net ≤ gross, one-third deduction rule), and packaged as a recommendation — a credit officer decides.

schema-constrained extraction · field-level confidence · DPA s.35: recommend, never decide

04Operations console

Approval queue, loan-pack review, tamper-evident audit viewer with live chain verification, evaluation dashboards, and Prometheus-format monitoring — all sourced from real runtime data.

HITL queue · audit chain SHA-256 prev_hash→hash · /api/metrics · SLO alerts

The money-movement guarantee

Six steps between "propose" and "move"

The walkthrough a risk officer asks for: how does a chat message become a debit? Answer — slowly, signed, and with a human in the middle.

Model proposesRules-first extraction stages the intent — the LLM never signs or executes anything.
Policy gatePer-transaction cap, daily cap, new-beneficiary cooling-off — deterministic, testable rules.
OTP step-up6-digit challenge held server-side, outside any LLM context, TTL 5 minutes.
Signed intentHMAC-SHA256 over the body with nonce + expiry — tamper-evident, replay-proof.
Human approvalA bank officer reviews risk-scored intent in the ops console. This is the DPA s.35 decision point.
Verified executionSignature, TTL and single-use nonce re-verified, then the core API is called with an idempotency key.
The model proposes. The policy gate gates. A human decides. The executor verifies. — Fee figures, interest and totals are always computed by deterministic tools; the LLM quotes, it never calculates.
